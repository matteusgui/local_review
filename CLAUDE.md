## Project layout

This repo's Flutter project lives in the `local_reviews/` subdirectory, not the repo root — run all Flutter/Dart commands from inside `local_reviews/`, not from the repo root.

`local_review` (repo root) is a local-first app for film reviews ("Keep your films and your data"). The project is currently the unmodified Flutter starter template (a counter app in `local_reviews/lib/main.dart`) — no film-review domain code has been written yet.

## Product vision

- **Local-first**: reviews and film data live on-device by default. The number of reviews a user can create without ever syncing to a remote server must never be limited — local use is always fully-featured, not a crippled trial of the "real" remote product.
- **Simple and performant**: the app deliberately stays lightweight and fast rather than feature-heavy.
- **Not a social network**: the key differentiator from competing film-review apps is the explicit rejection of social-network dynamics (feeds, engagement pressure, etc.) that some competitors have drifted into.
- **Encryption roadmap**: local data encryption is planned first; encryption of remote/synced data is a later phase, once remote sync exists.
- **Freemium model (once remote sync ships)**: free tier gets limited remote storage/sharing and a limited number of reviews per week/month that count toward remote sync; paid tier raises those limits. This freemium gating applies only to the remote/sync features — never to local review creation (see local-first point above).
- **Self-hosting**: users will be able to run their own instance of the remote server instead of using a hosted one.

None of this is implemented yet (see Architecture below) — treat it as the product direction to design toward, not current behavior.

## Commands

Run these from `local_reviews/`:

```bash
flutter pub get              # install dependencies
flutter analyze              # static analysis (uses flutter_lints via analysis_options.yaml)
flutter test                 # run all tests
flutter test test/widget_test.dart   # run a single test file
flutter run                  # run the app (device/emulator or -d chrome / -d linux, etc.)
flutter build <platform>     # e.g. apk, ios, linux, macos, web, windows
```

## Architecture

- Single-module Flutter app; all Dart source is under `local_reviews/lib/`, entry point `lib/main.dart`.
- Platform scaffolding exists for Android, iOS, Linux, macOS, Web, and Windows (all generated by `flutter create`, unmodified).
- Lints are configured in `local_reviews/analysis_options.yaml`, extending `package:flutter_lints/flutter.yaml`.
- Dart SDK constraint: `^3.12.2` (see `local_reviews/pubspec.yaml`).
